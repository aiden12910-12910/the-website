Privacy / 隐私:
This site does NOT track anything you do inside the games. Games run in a cross-origin iframe, so their clicks and keystrokes never reach this page. Only actions on this page (clicking links, typing in the comment box, switching tabs, etc.) are logged every 60 seconds and sent to GitHub Issues.
隐私:
本站不会追踪你在游戏内的任何操作。游戏在跨域 iframe 中运行，因此游戏内的点击和按键永远不会传到这里。只有本页面上的操作（点击链接、在留言框输入、切换标签页等）会被记录，每 60 秒打包发送到 GitHub Issues。
⚠️ About OAuth 2.0 / 关于 OAuth 2.0:
This site uses Google Identity Services (OAuth 2.0) for optional sign-in. Your Google password is never seen by this site — Google handles the login and only returns your email and a unique ID. You can revoke access anytime at myaccount.google.com/permissions.

本站使用 Google Identity Services（OAuth 2.0）提供可选的登录功能。本站永远看不到你的 Google 密码 —— 登录由 Google 处理，只返回你的邮箱和一个唯一 ID。你可以随时在 myaccount.google.com/permissions 撤销授权。

How "open site inside" works / “页面内打开”的使用说明

This site uses "openSiteInside" to load content within the current page. Hover the mouse over the top area to reveal a gray bar; click it to return to the "disguise" page. Alternatively, press the Esc key twice — the first press releases the mouse/keyboard from the game context, and the second returns you to the previous view. Some websites may open in a new tab because they reject being loaded inside another page.

本站使用 “openSiteInside” 在当前页面内加载内容。把鼠标移到页面顶部会显示一条灰色横条，点击它即可回到“伪装”页面。也可以按两次 Esc 键 —— 第一次把鼠标/键盘从游戏上下文中释放，第二次返回上一个视图。部分网站因为拒绝被嵌入其他页面，会在新标签页中打开。
