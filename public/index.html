How "open site inside" works / “页面内打开”的使用说明

Click a game link — it loads inside the current page. Hover the mouse over the top area to reveal a gray bar; click it to return to the home page. Alternatively, press the Esc key twice — the first press releases the mouse/keyboard from the game context, and the second returns you to the previous view. Some websites may open in a new tab because they reject being loaded inside another page.

点击游戏链接即可在当前页面内加载。把鼠标移到页面顶部会显示一条灰色横条，点击它即可回到首页。也可以按两次 Esc 键 —— 第一次把鼠标/键盘从游戏上下文中释放，第二次返回上一个视图。部分网站因为拒绝被嵌入其他页面，会在新标签页中打开。
